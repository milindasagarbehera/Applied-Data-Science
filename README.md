## Featured Highlights

### 1. Multimodal RAG Pipeline
*   **Problem:** Extracting insights from unstructured data (text + images).
*   **Solution:** Built a Retrieval-Augmented Generation system using Vector Databases to query across different media formats.
*   **Impact:** Reduced information retrieval time by 40% for complex technical manuals.

### 2. LSTM Sequence Modeling
*   **Problem:** Predicting mechanical failures before they occur in vehicle sensors.
*   **Solution:** Implemented a many-to-one LSTM architecture to process temporal sensor data.
*   **Tech:** PyTorch, StandardScaler, Matplotlib for residual analysis.

## Getting Started

To explore a specific project:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/milindasagarbehera/Applied-Data-Science.git
    ```
2.  **Navigate to a project folder:**
    ```bash
    cd Multimodal-RAG-System
    ```
3.  **Install requirements:**
    ```bash
    pip install -r requirements.txt
    ```
